# Space-simulation-of-milky-way-galaxy-
Simple visualization of the spiral arms structure of the Milky Way galaxy using basic mathematical principles, Python(Numpy and Matplotlib)
Description:  A spiral galaxy was visualized by using a simple logarithmic equation and plotted in 2D using parametric coordinates.
The stars are represented as points, and using Python libraries to create easy and quick mathematical calculations and data visualization.
Numpy was used to generate mathematical values and operations like angles, etc. Using linspace(), many theta values were generated, and sine, cos, and exponential calculations were performed.
Matplotlib was used to convert the data set into a visual graph and plot x-y coordinates and simulate the look-alike of a galaxy.
scatter() was used to plot the points(stars)
The spiral equation r = ae^bθ was used to calculate the spiral angles; the Cartesian coordinates were converted to polar coordinates and rotated multiple times to create spiral hands/arms.
a and b are adjustable parameters corresponding to the size and tightness of the spiral arms.
The output is a 2D spiral graph that simulates the Milky Way galaxy.
